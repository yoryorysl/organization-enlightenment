# Illuminati — Global Unity & Enlightenment

A professional informational website exploring the history, philosophy, principles, enlightenment concepts and membership-interest process associated with the Illuminati.

## About the Project

This website presents educational and informational material concerning:

- The historical Bavarian Illuminati
- Enlightenment-era ideas
- Modern narratives associated with the Illuminati
- Global unity and cooperation
- Personal development
- Knowledge and self-reflection
- Principles of responsible participation
- A voluntary membership-interest process

The website is designed as a clean, responsive experience for desktop and mobile visitors.

## Important Historical Distinction

The historically documented Bavarian Illuminati was founded by Johann Adam Weishaupt in Ingolstadt in 1776.

Modern claims concerning a continuing worldwide Illuminati organization are separate from the documented eighteenth-century history and should be evaluated critically.

This website therefore distinguishes historical information from modern narratives and encourages visitors to make informed decisions.

## Application Functionality

The membership-interest form currently performs client-side validation and displays a confirmation message in the browser.

Because GitHub Pages provides static hosting, the current form does not automatically transmit applications to an external email address or database.

A form-processing service or backend can be connected separately if actual application submission and storage are required.
